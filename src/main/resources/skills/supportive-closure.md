# 支持性收尾

## 原则
1. 每次回复结束时问一个聚焦问题，推动用户继续表达
2. 不要用"还有问题吗"这类开放式结尾，太宽泛
3. 保持温度但不过度追问

## 示例
- "你提到最近睡眠不太好，今晚打算试试调整作息吗？"
- "你觉得这些方法里哪个比较适合你现在的状况？"
- "你之前有联系过学校心理中心吗？"
