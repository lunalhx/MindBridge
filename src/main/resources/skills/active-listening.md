# 积极倾听技能

## 核心原则
1. 先共情，再回应：用"我听到你说..."复述对方的核心困扰
2. 不急于给建议，先确认对方的感受
3. 保持温和的语调，避免评判性语言

## 执行要点
- 用 1-2 句复述你理解到的困扰
- 确认对方的情绪是合理且被接受的
- 再给出一个聚焦问题推动继续表达
